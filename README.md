# 안녕, 오예린 이야기 앱

`index.html`을 열면 바로 사용할 수 있는 독립형 어린이 이야기 앱입니다.

## 주요 기능

- 한국어·영어 이야기 전환
- 0세부터 7세까지 연령별 문장 구성
- 주인공 이름 변경
- 동화·동요·이솝우화·그리스 신화 카테고리
- 기기에 설치된 한국어·영어 음성 선택과 읽기 속도 조절
- 부모님이 이야기를 직접 녹음하고 다시 들려주는 기능
- 이름, 나이, 녹음 자료를 브라우저에만 보관

## 사용 방법

1. `index.html`을 Chrome 또는 Edge에서 엽니다.
2. 언어, 나이, 이야기와 목소리를 선택합니다.
3. `이야기 듣기`를 누릅니다.
4. 부모 목소리를 남기려면 녹음 영역에서 녹음을 시작하고 마친 뒤 저장합니다.

마이크 녹음은 브라우저 보안 정책 때문에 배포된 HTTPS 주소 또는 localhost에서 가장 안정적으로 동작합니다. 선택 가능한 실제 음성은 사용 기기와 브라우저에 설치된 음성에 따라 달라집니다. 부모 목소리 기능은 인공지능 목소리 복제가 아니라, 부모님이 읽은 이야기를 안전하게 기기 안에 녹음해 재생하는 방식입니다.
