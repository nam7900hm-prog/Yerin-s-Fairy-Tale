# 예린의 동화구연 앱

아이폰과 삼성폰에서 사용할 수 있는 모바일 동화·동요 구연 웹앱입니다.

## 이번 수정 내용

- `부모 녹음`을 별도 탭으로 분리했습니다.
- 부모 목소리는 `낭독 목소리` 목록에 포함하지 않았습니다.
- 녹음할 동화·동요를 선택하면 해당 글 또는 가사가 바로 표시됩니다.
- `직접 입력`을 선택하면 제목과 글·가사를 자유롭게 입력할 수 있습니다.
- 부모가 직접 녹음하거나 기존 MP3·M4A·WebM·WAV 파일을 올릴 수 있습니다.
- 저장한 음원을 다시 재생하고 기기로 내려받거나 삭제할 수 있습니다.
- iPhone Safari에서 지원되는 M4A 녹음 형식을 우선 사용합니다.
- `iPhone 녹음 점검` 버튼으로 HTTPS, 마이크, 녹음 기능과 저장 형식을 확인할 수 있습니다.
- 녹음 파일은 서버가 아니라 현재 휴대폰 브라우저 내부에 저장됩니다.

## 부모 녹음 사용법

1. 앱에서 `부모 녹음` 탭을 누릅니다.
2. `녹음할 내용`에서 동화나 동요를 고릅니다.
3. 화면에 나타난 글이나 가사를 보며 `녹음 시작`을 누릅니다.
4. 처음 사용할 때 마이크 권한을 허용합니다.
5. 다 읽은 뒤 `녹음 끝내기`를 누릅니다.
6. 재생 버튼으로 확인한 뒤 필요하면 파일을 내려받습니다.

직접 만든 MP3가 있으면 `MP3·녹음 파일 업로드`를 눌러 해당 이야기나 동요에 저장할 수 있습니다.

## iPhone 사용 시 주의사항

- 카카오톡 안에서 열지 말고 Safari 주소창에서 앱 주소를 직접 엽니다.
- 반드시 `https://`로 시작하는 배포 주소를 사용합니다.
- Safari가 마이크 사용을 물으면 `허용`을 누릅니다.
- iPhone 녹음은 기기에 따라 M4A 형식으로 저장됩니다.
- 홈 화면 추가는 Safari의 공유 버튼에서 `홈 화면에 추가`를 선택합니다.

## 삼성폰 사용 시 주의사항

- Chrome에서 앱 주소를 직접 엽니다.
- 마이크 권한을 허용합니다.
- 삼성·Chrome 녹음은 WebM 형식으로 저장될 수 있습니다.
- Chrome 메뉴에서 `홈 화면에 추가` 또는 `앱 설치`를 선택합니다.

## 파일 안내

- `index.html`: 앱 화면
- `styles.css`: 화면 디자인과 휴대폰 배치
- `app.js`: 동화·동요 및 낭독 기능
- `recording.js`: 부모 녹음, 업로드, 기기 저장, 다운로드 기능
- `작업보관_배포지시서.md`: 보관과 재배포 방법

## 중요

녹음과 업로드 음원은 휴대폰의 해당 브라우저 안에만 저장됩니다. 브라우저 데이터나 앱을 삭제하면 함께 없어질 수 있으므로 중요한 녹음은 반드시 `내려받기`로 별도 보관하세요.
