# 안녕, 오예린 이야기 앱

`index.html`을 열면 바로 사용할 수 있는 독립형 어린이 이야기 앱입니다.

## 주요 기능

- 한국어·영어 이야기 전환
- 0세부터 7세까지 연령별 문장 구성
- 주인공 이름 변경
- 동화·동요·이솝우화·그리스 신화 카테고리
- 기기에 설치된 한국어·영어 음성 선택과 읽기 속도 조절
- 서울말 할머니·다정한 할아버지·동화 선생님·잠자리·등장인물별 구연 방식
- 놀람·슬픔·대화·도입 장면과 연령에 따른 속도·음높이·문장 사이 쉼 연출
- 부모님이 이야기를 직접 녹음하고 다시 들려주는 기능
- 이름, 나이, 녹음 자료를 브라우저에만 보관

## 사용 방법

1. `index.html`을 Chrome 또는 Edge에서 엽니다.
2. 언어, 나이, 이야기와 목소리를 선택합니다.
3. `이야기 듣기`를 누릅니다.
4. 부모 목소리를 남기려면 녹음 영역에서 녹음을 시작하고 마친 뒤 저장합니다.

마이크 녹음은 브라우저 보안 정책 때문에 배포된 HTTPS 주소 또는 localhost에서 가장 안정적으로 동작합니다. 선택 가능한 실제 음성은 사용 기기와 브라우저에 설치된 음성에 따라 달라집니다. 부모 목소리 기능은 인공지능 목소리 복제가 아니라, 부모님이 읽은 이야기를 안전하게 기기 안에 녹음해 재생하는 방식입니다.

## 휴대전화에서 소리가 나지 않을 때

- 삼성폰은 Chrome을 권장하며, 설정에서 `텍스트 읽어주기`의 Google 또는 삼성 음성 엔진과 한국어 음성을 활성화합니다.
- 아이폰은 Safari를 권장하며, 무음 모드를 해제하고 미디어 음량을 높입니다.
- 카카오톡·문자 앱 안의 미리보기 브라우저 대신 Chrome 또는 Safari에서 주소를 직접 엽니다.
- ZIP 안의 파일을 휴대폰에서 직접 여는 방식보다 HTTPS 웹 주소로 배포해서 사용하는 것이 안정적입니다.

구연 방식은 실제 특정인의 목소리를 복제한 것이 아니라 휴대전화에 설치된 음성의 속도, 높낮이, 호흡과 문장별 연출을 조절하는 방식입니다. 기기마다 기본 음색은 조금씩 달라질 수 있습니다.
